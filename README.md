# namewatch

Слушает микрофон и плавно приглушает системный звук, когда вас зовут по имени. Для Ubuntu (PulseAudio / PipeWire).

```
микрофон → VAD (только речь) → детектор имени → приглушение (pactl, с fade) → возврат после тишины
```

## Установка

```bash
sudo apt install libportaudio2 pulseaudio-utils unzip curl pipx
pipx install .                      # из каталога проекта
./scripts/download-model.sh         # модель Vosk ~45 МБ
mkdir -p ~/.config/namewatch && cp config.example.toml ~/.config/namewatch/config.toml
```

Впишите свои имена в `[detector] names` (строчными буквами, со всеми формами: «вася», «василий», «васёк»).

## Использование

```bash
namewatch devices      # найти микрофон, прописать в [audio] device
namewatch test-duck    # проверить, что громкость приглушается и возвращается
namewatch wav rec.wav  # прогнать запись (16 кГц, моно) без микрофона
namewatch run          # запуск
```

Автозапуск: `systemd/namewatch.service` (инструкция в первой строке файла).

## Как это работает и что важно знать

- **Два этапа.** По частичному результату Vosk громкость падает сразу (малая задержка), итоговое распознавание с уверенностью ≥ `min_conf` подтверждает, иначе громкость возвращается (`reject`).
- **Лёгкость.** VAD отсекает тишину, Vosk получает аудио только во время речи, поэтому в простое нагрузка на CPU около нуля. Маленькая модель работает быстрее реального времени на любом современном CPU.
- **Имя должно быть в словаре модели.** Редкие имена Vosk может не знать (при старте будет предупреждение). Тогда используйте `engine = "oww"` с обученной openWakeWord-моделью (`pipx inject namewatch openwakeword`).

## Нюансы

1. **Микрофон должен слушать комнату**, а не быть в наушниках. Подойдёт настольный микрофон, веб-камера или ноутбучный микрофон.
2. **Звук из колонок попадает в микрофон.** В наушниках проблемы нет. Если играют колонки, включите эхоподавление PipeWire: модуль `libpipewire-module-echo-cancel`, и выберите его источник как устройство.
3. **Ложные срабатывания** на ТВ/подкасты/созвоны: поднимите `min_conf`, сократите список имён, уберите короткие формы.
4. **Громкость меняется у всего устройства вывода.** Если вы вручную меняете громкость во время приглушения, по возвращении она будет сброшена к значению до приглушения.
5. **Аварийный выход.** При Ctrl+C и SIGTERM громкость возвращается. При `kill -9` или падении питания — нет; исправить: `pactl set-sink-volume @DEFAULT_SINK@ 100%`.
6. **Приватность.** Всё распознавание офлайн, звук никуда не отправляется и не сохраняется.
7. **Ubuntu 22.04** имеет Python 3.10: поддерживается (используется `tomli`). `webrtcvad-wheels` ставится готовым wheel; без него работает запасной VAD по громкости.
